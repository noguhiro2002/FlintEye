<a id="container"></a>
## コンテナ

`linux/amd64`または`linux/arm64`には`ghcr.io/noguhiro2002/flinteye:@IMAGE_VERSION@`を使用してください。公開イメージは匿名でのプルを許可していますが、プライベートテストには認証されたGHCRログインが必要です。プレビューイメージにはコンテナの`latest`タグはありません。添付の`compose.yaml`と、`documentation.zip`のDockerガイドを使用してください。

<a id="changes-in-this-version"></a>
## このバージョンの変更点

プレビュー5では、MediaMTXを1.21.4へ更新し、Go 1.27.4でビルドしています。コンテナにはDebianの修正済みzlibを導入し、ビルドに使うpipと初期導入用のwheelを取り除きました。インストール検証では、WebRTCプレーヤーが再読み込みされた場合も、映像が進むこと、選択したカメラの映像が出ること、音声を受信できることを確認します。

Linuxのコマンドインストーラーは、パッケージ管理上の版番号が同じ場合も、インストール済みのプレビューを差し替えます。更新するときはFlintEyeを終了し、このリリースのインストールコマンドを実行してください。

amd64とarm64のコンテナは、導入できる修正版があるHigh・Criticalの検出が0件で、配布用のスキャンに合格しました。Debian 13で修正版を待っている検出は、ビルドの`container-advisories-*`成果物に記録しています。

配布時の自動検査で、APIの全87操作について、アクセス拒否を含む実際のHTTP応答を確認しました。録画先の容量不足から録画一覧が復旧することと、Composeの更新・ロールバックで元の録画が保持されることも確認しました。成功応答と異常系の検査結果は監査レポートで確認できます。[配布前の自動検査](https://github.com/noguhiro2002/FlintEye/actions/runs/44712702586)

インストールQAプロセスでは、実際にインストールされたAPIとブラウザを使用したセットアップ、2台の仮想カメラ、音声/ビデオ、録画再生/ダウンロード、ビューアーアクセス、停止（Stop）、終了（Quit）、アンインストール、およびデータ保持状態での再インストールを検証しています。32ケースのビルドマトリックスと、それに続く10件の匿名オンラインインストール/GHCRテストケースを通じて、欠落や失敗の手順を記録しています。macOSでの初回起動時にはLaunch Servicesを使用し、OSによる承認拒否があった場合はAPI/GUIが未検証の状態として手動対応が必要であると報告されます。インストーラーの出力では、ファイルのコピー、起動要求、初回起動時の許可が区別されます。バックエンドの検証では、構成可能なローカルメディアポートおよびステレオOpusプレビュー変換も対象としており、選択された録画オーディオ形式は維持されます。詳細なテスト済みビルドと制限事項については、`QA-RESULTS.json`およびインストールQAガイドを参照してください。

ネイティブコントロールウィンドウがPNGアイコンを直接読み込むようになったため、Pillow/Tk拡張機能が欠落していてもアプリケーションが終了することはなくなりました。OSのサービス停止要求時に所有権のクリーンアップが完了するようになり、multiviewはRocky LinuxにインストールされたDejaVuフォントを検出できるようになりました。

この開発プレビューには、対応するオンラインインストーラーでのmacOSカメラ、セットアップ、アイコンの修正が含まれています。スクリーン入力はカメラの検索から除外され、キャプチャ前に確認されるため、古いカメラインデックスがディスプレイを選択してしまうことが防止されます。管理者セットアップはブラウザを使用し、ネイティブのセットアップ支援機能には接続アドレスと一度限りのコードが表示されます。バンドルおよび実行中のアプリケーションのアイコン設定には、FlintEyeシンボルが使用されます。

その他の1.2.0の変更点には、信頼されたLANでのHTTPSセットアップ、認証付きRTSPSカメラアドレス、修正されたUSBキャプチャモード、オプションのカメラごとオーディオ（デフォルトでオフ）、一貫したアンインストール手順が含まれます。設定と録画データはアプリケーションの外側に保持されます。共有モニタリングステータス、停止（Stop）と終了（Quit）の区別、録画完了チェック、および所有プロセスのクリーンアップも引き続き含まれています。

ビルド時の必須32ケースのうち、24ケースが全7段階に合格しました。macOSのDMG・スクリプト導入8ケースは、インストール、整合性、削除に合格しました。OSの初回起動承認が必要なため、導入後のAPI・画面操作、終了、データを保持した再インストールは未実施です。各段階の結果は `QA-RESULTS.json` に記録しました。実機確認は8項目とも未完了です。配布URLとGHCRは公開後に自動検証します。[ビルド結果](https://github.com/noguhiro2002/FlintEye/actions/runs/44712701442)
