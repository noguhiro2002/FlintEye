# 既知の問題 — UNDER DEVELOPMENT

[English](KNOWN_ISSUES.md) · [Documentation](README.ja.md)

このソースファーストのプレビューは安定版ではありません。ブラウザでのレビューにより、合成データを使用して26グループのインターフェイス上の問題が再現されました。これらは作業待ちのものであり、このスナップショットに含まれる修正ではありません。このレビューでは物理カメラの検証は行われておらず、すべての問題が発見されたことを立証するものでもありません。

| 領域 | 既知の制限事項と現在の注意事項 |
| --- | --- |
| 設定の下書き | 更新、ナビゲーション、競合の復旧、および一部のカメラ削除操作により、保存されていない編集内容が破棄される場合があります。ページやデバイスを切り替える前に、タスクを1つずつ保存してください。高度なJSONには個別の保存動作があり、未保存のインジケーターが不完全です。 |
| カメラの検査とPTZ | 応答の遅延により、カメラの切り替えまたは削除後に古い情報が適用される場合があります。カメラリストを編集する前に検査を完了させ、PTZを操作する前に選択したカメラと機能を確認してください。 |
| カメラの識別情報 | IPカメラの削除と再追加を行うと、重複するデフォルトパスが生成される可能性があります。保存する前に、すべてのカメラパスが一意であることを確認してください。 |
| 接続および読み込みエラー | 一部のページで、読み込み、空の結果、部分的な失敗、または未知の認証状態が混同される場合があります。サービス障害中の「Public viewer」は、認可バイパスの証拠ではありません。再試行してサーバーの状態を確認してください。 |
| 録画 | 無効な日付範囲が結果なしとして表示される場合や、部分的なフィルターの失敗により利用可能な録画が非表示になる場合があります。日付の順序を確認して再試行してください。再生ダイアログにはキーボードフォーカスに関する問題があります。 |
| 狭いディスプレイとアクセシビリティ | 一部のレイアウトがスマートフォンやタブレットでオーバーフローします。選択ラベル、キーボードフォーカス、コントラスト、および初回実行時のフォームの間隔は、さらなる作業が必要です。現在はデスクトップ幅のウィンドウが最も実用的なテスト環境です。 |
| ガイダンスと検索 | 設定検索が一部のラベルを見逃したり、初回実行時のガイダンスが別のページをハイライトしたりすることがあり、一部の空の状態でのアクションが誤解を招くものになっています。 |

自動ビルドでは、起動、初期認証、バンドルされたメディアツール、合成録画および再生がチェックされます。Windowsインストーラーのチェックでは、アクティブなAPIと保持されたデータを使用したアンインストールの検証も行われます。これらは、実機でのUSB/IPカメラ、マイク/プライバシー権限、スリープ/復帰、最小OS、自動起動、またはデスクトップ終了のチェックに**代わるものではありません**。

公開インストーラーとGHCRイメージの準備が進められています。最初のプレビューを公開する前に、メンテナーはWindows x64、M1 Mac、Linux x64の受入確認を行い、対応するソース/ライセンスを確認する必要があります。その他のCPU/OSの組み合わせについては、引き続き明示的にデバイステストの対象となります。[受入チェックリスト](ACCEPTANCE.ja.md)を参照してください。

再現可能な問題は[Issues](https://github.com/noguhiro2002/FlintEye/issues)を通じて報告してください。レポートから資格情報、セットアップトークン、プライベートカメラのURL、個人用の映像を削除してください。[プライベートセキュリティチャンネル](../.github/SECURITY.ja.md)を使用してセキュリティ脆弱性を報告してください。
