# 既知の問題と WebApp のレビュー状況

[English](KNOWN_ISSUES.md) · [ドキュメント](README.ja.md)

FlintEye は**UNDER DEVELOPMENT**であり、安定版リリースではありません。2026年11月15日の Terra ブラウザレビューにより、26グループのインターフェイスの不具合が特定されました。以下の変更は、現在のソースコードにおけるそれらのグループに対処するものです。これらの変更より前にビルドされたインストーラーの成果物には、以前のインターフェイスが依然として含まれており、Windows または macOS でテストする前に、更新されたソースからビルドし直す必要があります。

<a id="changes-from-the-review"></a>
## レビューからの変更点

| レビューの指摘事項 | 更新されたソースにおける動作 |
| --- | --- |
| 1, 2, 13, 25 — 未保存の設定と読み込み | 画面の移動、Refresh、および2か所の Discard ボタンでは、未保存のフォームや Advanced JSON の編集内容を破棄する前に確認が行われます。個別のデバイス/アカウント操作を実行するには、既存の変更を保存するか破棄する必要があります。Advanced JSON に読み上げ用のラベルと未保存状態の表示を追加し、置き換える際には未保存のフォームの変更に関する警告が表示されます。一部の項目だけを数えた不正確な変更件数の表示をやめました。USB の検出に失敗しても、その他の設定は引き続き利用可能です。設定を読み込めない場合は「利用不可」と表示し、既定値を実際の設定と誤認させないようにしました。 |
| 19, 21, 22, 23, 24 — カメラの識別とカメラ検査 | カメラを切り替えると、PTZ の状態が分離されます。カメラの削除や設定変更後に届いた古い検査結果は反映しません。新しいカメラパスは一意であり、重複したパスや空のパスは保存前に拒否されます。カメラ検査の失敗により、前回の成功状態がクリアされます。カメラ検査では、設定を自動的に変更する代わりに、明示的な **Apply recommended FPS** アクションが提示されます。 |
| 3 — 認証 | 利用できない認証エンドポイントは、認証なしで閲覧可能と誤表示するのではなく、エラーと **Retry connection** を表示します。通信にはタイムアウトを設けています。ただし、フォルダー選択画面はユーザーの操作を待ちます。 |
| 16, 18 — 録画プレーヤー | プレーヤーを開くとフォーカスが内部に移動し、キーボードナビゲーションが内部に維持され、背景の操作が無効になり、閉じるときにフォーカスが復元されます。再生コントロールはその録画を識別します。 |
| 17, 20 — 録画の検索条件 | 日付範囲が逆になっている場合は、無効な検索条件を送信せずにインラインエラーが表示されます。録画とストリームのフィルターは個別に読み込まれ、フィルターのリクエストが失敗しても利用可能な映像が隠されることはありません。フィルターの変更中や更新の失敗時も、保持された結果は以前の結果として識別されます。 |
| 6, 7, 26 — Live View と Multiview | ポーリングは順次実行され、古くなった応答は無視されます。削除された選択項目は、利用可能なソースにフォールバックします。読み込み中、サービスの障害、および未設定の状態には、それぞれ明確なメッセージが表示されます。 |
| 4, 5 — 小型画面 | ヘッダー、コントロール、カメラカード、テーブルは、狭い幅で折り返されるか縮小します。長い名前や URL によってページが強制的に広げられることはなくなりました。モバイルナビゲーションは、そのコンテンツに必要な高さのみを使用します。 |
| 8 — 設定の検索 | Encoder が含まれます。検索では、すべてのフィールドを約束するのではなく、設定カテゴリと一般的なキーワードとしてその範囲が説明されます。 |
| 9, 10 — セットアップとサインイン | セットアップフィールドには、余白を設けた縦並びのレイアウト、FlintEye のブランディング、および表示されるパスワード要件が使用されます。必須のサインインでは、移動先のない Back ボタンは表示されません。 |
| 11, 12 — アクセシブルな状態とコントラスト | 現在のページや、カメラ・Multiview の選択状態をスクリーンリーダーなどの支援技術に伝えます。カメラコントロールは選択ボタンとは別になっています。小さな PTZ の説明テキストのコントラストが強くなっています。 |
| 14, 15 — ガイダンスと空の状態 | ガイドを開いても、別のページがあたかもアクティブであるかのように装飾されることはなくなりました。空のカメラ/出力/録画の状態では状況が説明され、空の録画リストではページネーションが省略されます。 |

<a id="validation-and-remaining-limits"></a>
## 検証と残りの制限事項

再発防止用のテストでは、ビルド済みフロントエンド、Chromium、およびテスト用に用意した API 応答を使用します。遅延および失敗したリクエスト、未保存の編集内容の保護、カメラの切り替え、キーボード操作、狭いレイアウトをテストします。外部ホストへのリクエストをブロックし、物理カメラには接続しません。テストコマンドについては、[貢献ガイド](../.github/CONTRIBUTING.ja.md)を参照してください。

- **実機での受け入れテストを引き続き必須とします:** 対象の端末上で、Windows および macOS のデスクトップ動作、物理的な USB/IP カメラ、PTZ の移動/停止、マイク/プライバシーの権限、スリープ/復帰、最小 OS のサポート、実際の動画デコードを確認する必要があります。Linux ブラウザのテストでは、すべてのブラウザやスクリーンリーダーとの互換性は確立されません。
- **競合する設定は自動的にマージされません:** 競合が発生した場合でも、未保存の編集内容は画面に残ります。未保存の編集内容を明示的に破棄して最新の設定を再読み込みする前に、必要な変更をコピーしてください。
- **終了方法は導入方法によって異なります:** ブラウザを閉じてもモニタリングは実行され続けます。デスクトップユーザーは **Stop monitoring and quit** からアプリを停止します。Docker/systemd ユーザーはサーバーサービスを停止します。
- **リリースステータス:** 一般公開用インストーラーと GHCR イメージは、Windows x64、M1 Mac、Linux x64 での受け入れテスト、および対応するソース/ライセンスのレビューが完了するまで制限されたままになります。既存の Actions 成果物は開発ビルドであり、安定版リリースではありません。[受け入れチェックリスト](ACCEPTANCE.ja.md)を参照してください。

再現可能な新しい問題は、[Issues](https://github.com/noguhiro2002/FlintEye/issues) から報告してください。レポートから資格情報、セットアップトークン、プライベートカメラの URL、個人の映像を削除してください。脆弱性については、[プライベートセキュリティチャンネル](../.github/SECURITY.ja.md)を使用してください。
