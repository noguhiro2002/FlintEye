# FlintEye の使用方法

[English](USER_GUIDE.md)

[Documentation](README.ja.md)

<a id="start-and-sign-in"></a>
## 起動とサインイン

Windows のスタートメニュー、macOS のアプリケーションフォルダー、Linux のアプリランチャーから FlintEye を開きます。初回はアプリからブラウザーにセットアップの許可が渡されます。12〜1024文字の管理者パスワードを決め、2回入力します。途中でタブを閉じた場合は、アプリのメニューから **Open FlintEye** を選ぶと再開できます。通常のローカルアドレスは `http://127.0.0.1:18080` です。セットアップ後は `admin` でサインインします。[Docker・systemd の初期設定](LAN_ACCESS.ja.md#初回所有権と日常的な使用)

英語版の入門ツアーでは、カメラとストレージについて紹介しています。
スキップすることも、アプリケーションから開き直すこともできます。

<a id="add-cameras"></a>
## カメラの追加

**Settings** で、接続されている USB カメラを検出するか、IP カメラを追加します。
IP カメラの場合は、この画面でアドレスと資格情報を入力します。ターミナル コマンド内に資格情報を記述しないでください。
設定を適用し、**Live View** を確認します。サポートされている ONVIF カメラの場合、検出および PTZ 制御を利用できます。

オペレーティング システムからカメラへのアクセス許可を求められる場合があります。FlintEye に許可を与えてください。
カメラとシステムの設定を変更できるのは管理者のみです。

<a id="recording-and-storage"></a>
## 録画とストレージ

Settings でカメラの録画を有効にします。**Recordings** を開き、ストリームと録画を選択して再生します。

初期の保持制限は **7 日間** です。初期の容量の推奨値は、**50 GB または選択したフォルダーの空き容量の半分**のいずれか小さい方です。
これは固定設定として保存され、空き容量に合わせて自動的に増加することはありません。
制限に達した方の基準に従って、完了した最も古い録画が削除されます。7 日間は最大値であり、保証された履歴の長さではありません。

**Settings → 録画** で別のフォルダーを選択するか制限を調整し、[変更を保存] をクリックします。フォルダー ピッカーは、インストール先のコンピューター上のデスクトップ アプリを使用しているときに利用できます。リモート ブラウザではサーバー上のパスを入力します。[空き容量から提案] をクリックすると、保存せずに容量の提案値が入力されます。すべての録画設定がメインの Settings フォームに統合され、個別のインストール設定パネルは削除されました。
フォルダーを変更しても既存のファイルは移動されません。[以前の場所からの録画を表示する] はデフォルトで有効になっています。
これをオフにすると、それらの録画がリストや再生画面から非表示になりますが、削除されたり既存の保持ルールが無効化されたりすることはありません。
ディスクが利用できない状態になると、再接続されるまで録画にアクセスできなくなります。

空き容量の予備を維持できない場合、FlintEye は録画を一時停止します。
状況を説明するバナーが表示されます。クリーンアップのタイミングやインポートされたファイルの詳細については、[ストレージの詳細](DISTRIBUTION.ja.md#recording-lifecycle)を参照してください。

<a id="event-recordings"></a>
## 設備の異常が起きる直前の映像を残す

1. 管理者で **Settings → Recording → Event recordings** を開き、有効にします。FlintEye が書き込める既存フォルダーを指定します。ループ録画の現在および過去の保存先とは別に用意してください。Docker では、コンテナ内の永続化したパスを指定します。
2. **Save event settings** を押し、表示されたトークンを控えます。さかのぼる秒数の上限は初期値で 600 秒です。対象カメラのループ録画も有効にしておきます。
3. 設備からカメラ ID と秒数を送信します。発生時刻を省略すると、FlintEye が受信した時刻を使います。[設備からの送信例](advanced/API.ja.md#equipment-recording-events)

保存状況と映像は **Recordings → Event recordings** で確認できます。対象区間の末尾を録画中の場合は、現在のセグメントが閉じるまで待ちます。セグメントが 10 分設定なら、待ち時間は数分になることがあります。録画のない区間があれば、保存できた部分を表示します。ループ録画の自動削除はイベントの保存先には適用されません。

<a id="viewer-access-and-other-devices"></a>
## ビューアのアクセスとその他のデバイス

アクセスを共有する前に、**Settings → ランタイムとアクセス** で `viewer` のパスワードを設定してください。他の保留中の変更を先に保存または破棄してください。パスワードを更新すると全員がサインアウトされます。その後、管理者として再度サインインしてください。ビューアは視聴できますが、設定の変更はできません。
別の端末から接続するには、**Settings → Runtime & access** で **Allow access from other devices on LAN or VPN (HTTPS)** をオンにします。保存して FlintEye を再起動し、閲覧する端末で FlintEye の CA 証明書を信頼します。[LAN・VPN 接続の手順](LAN_ACCESS.ja.md#アクセスの有効化)
ローカルの HTTP リスナーおよび MediaMTX リスナーはループバック上に維持してください。インターネットに直接公開しないでください。

<a id="stop-update-or-uninstall"></a>
## 停止、アップデート、またはアンインストール

ブラウザのタブを閉じても録画は継続して実行されます。
設定を利用可能な状態に保ったままカメラと録画を一時停止するには、**Stop monitoring** を選択します。完全に終了するには、Windows/macOS のトレイ メニューまたは Linux のコントロール ウィンドウで **Quit FlintEye** を選択します。停止状態はデフォルトで記憶されます。[監視インジケーターと起動時の設定](MONITORING.ja.md)を参照してください。
デスクトップの起動はログイン後に実行されます。無人サーバーとして運用するには systemd または Docker を使用してください。
手動でのスリープ、ログアウト、またはシャットダウンを行うと、監視が中断されます。

**Settings → 一般 → ソフトウェア アップデート** でアップデートを確認します。アップデートは手動でインストールします。トップ バーにある [はじめに] ボタンをクリックすると、入門ツアーを再度開くことができます。
Quit FlintEye、設定と録画インベントリのバックアップを作成し、置換パッケージをインストールして、再起動します。
通常、アンインストールを行っても設定と録画は保持されます。データを削除するには、別途明示的な選択が必要です。

## カメラの音声（次期開発版）

**Settings → Cameras** で登録済みのUSBまたはIPカメラの **Camera audio** を開き、**Check audio input** を押します。各カメラの初期値はオフです。マイクや音声トラックを確認できない機種では、チェック欄は選択できません。LinuxではUSBマイク用のALSAデバイスにアクセスできることを確認してください。macOSやWindowsでマイクの権限を求められた場合は、使用するカメラに合わせて許可します。

**Standard**（16 kHz・16 bit・モノラルPCM）、**High**（48 kHz・24 bit）、**Middle**（12 kHz・16 bit）、**Low**（8 kHz・16 bit）、**Custom** から選べます。Customではサンプリング周波数とチャンネル数、PCMのビット深度、またはAACの目標ビットレートを指定します。保存後、**Live View** ではプレーヤーのミュートを解除して音を聞けます。保存された音声は、新しい完了済みの録画を **Recordings** で開いて確認します。
