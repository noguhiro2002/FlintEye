# FlintEyeの使い方

[English](USER_GUIDE.md)

[ドキュメント](README.ja.md)

<a id="start-and-sign-in"></a>

## 起動とサインイン

スタートメニュー（Windows）、アプリケーション（macOS）、またはアプリケーションランチャー（Linux）からFlintEyeを開きます。
初回起動時のウィンドウでは、管理者パスワードの入力を求められます（12〜1024文字、確認のため2回入力）。
デフォルトのパスワードはありません。セットアップを閉じると、次回の起動時まで設定が延期されます。
ブラウザーで http://127.0.0.1:18080 が開きます。`admin` としてサインインしてください。

英語のスタートガイドツアーで、カメラとストレージについて紹介されます。
ツアーはスキップでき、アプリケーションからいつでも再度開くことができます。

<a id="add-cameras"></a>

## カメラの追加

**Settings**（設定）で、接続されたUSBカメラを検出するか、IPカメラを追加します。
IPカメラの場合は、この画面でアドレスと認証情報を入力します。ターミナルコマンドに認証情報を含めないようにしてください。
設定を適用し、**Live View**（ライブビュー）を確認します。対応しているONVIFカメラでは、自動検出とPTZ制御が利用できます。

OSからカメラへのアクセス許可を求められる場合があります。FlintEyeに対して許可してください。
カメラおよびシステム設定を変更できるのは管理者のみです。

<a id="recording-and-storage"></a>

## 録画とストレージ

Settings（設定）でカメラの録画を有効にします。**Recordings**（録画）を開き、ストリームと録画を選択して再生します。

初期の保持期間上限は **7日間** です。初期の容量推奨値は、**50 GBまたは選択したフォルダーの空き容量の半分** のいずれか小さい方です。
これは固定設定として保存され、空き容量が増えても自動的に増加することはありません。
いずれかの上限に先に達すると、最も古い完了済みの録画から削除されます。7日間は最大値であり、保証された履歴期間ではありません。

**Settings → Recording** で別のフォルダーを選択するか制限を調整し、**Save changes** をクリックします。フォルダー選択画面は、インストール先のコンピューターでデスクトップアプリを使用している場合に利用できます。リモートブラウザーの場合はサーバー上のパスを入力します。**Suggest from free space** は、保存せずに推奨容量を入力します。録画設定はメインのSettings画面に統合し、別に表示されていたインストール設定欄は削除しました。
フォルダーを変更しても、既存のファイルは移動されません。**Show recordings from previous locations**（以前の場所の録画を表示）はデフォルトでオンになっています。
これをオフにすると、それらの録画が一覧や再生画面から非表示になります。録画が削除されたり、既存の保持ルールが無効になったりすることはありません。
ディスクが利用できない場合、再接続されるまで録画にアクセスできなくなります。

FlintEyeは、空き容量の確保分を維持できない場合、録画を一時停止します。
その状態はバナーで説明されます。クリーンアップのタイミングやインポートされたファイルについては、[ストレージの詳細](DISTRIBUTION.ja.md#recording-lifecycle)を参照してください。

<a id="viewer-access-and-other-devices"></a>

## 閲覧者アクセスとその他のデバイス

アクセスを共有する前に、**Settings → Runtime & access** で `viewer` パスワードを設定してください。まず他の保留中の変更を保存するか破棄します。パスワードを更新すると全員がサインアウトされるため、その後管理者として再度サインインしてください。閲覧者は視聴できますが、設定を変更することはできません。
LANからのアクセスにはHTTPSリバースプロキシが必要です。[サーバーガイド](DISTRIBUTION.ja.md#user-installation)の手順に従ってください。
ローカルのHTTPおよびMediaMTXリスナーはループバックに留めてください。これらをインターネットに直接公開しないでください。

<a id="stop-update-or-uninstall"></a>

## 停止、更新、アンインストール

ブラウザーのタブを閉じても、録画は継続されます。
停止するには、Windows/macOSのトレイメニューまたはLinuxのコントロールウィンドウで **Stop monitoring and quit**（監視を停止して終了）を選択します。
デスクトップ版の自動起動はログイン後に実行されます。無人サーバー運用にはsystemdまたはDockerを使用してください。
手動でのスリープ、ログアウト、またはシャットダウンを行うと監視が中断されます。

**Settings → General → Software updates** でアップデートを確認します。アップデートは手動でインストールされます。トップバーの **Getting started** ボタンを押すと、入門ツアーが再度開きます。
監視を停止し、設定と録画インベントリをバックアップしてから、新しいパッケージをインストールして再起動してください。
通常、アンインストールしても設定と録画は保持されます。データを削除するには、別途明示的な選択が必要です。
